Install

Extension in three steps

  1. Download the extension (.zip) and unzip it.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the deep-work-field-extension folder.
  3. Come back here. The status in the top bar changes to connected; there is no ID to paste.

Not in the Chrome Web Store yet, so Chrome loads it in Developer mode. The page talks to it only through chrome.runtime.sendMessage with externally_connectable, no page injection. Also on GitHub.
