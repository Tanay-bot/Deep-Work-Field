    Smoothed screen and face cues. On-task screen with head down counts as writing, not drift.

    Resume, verified

    The fragment link lands on the twin-safe passage; the check fails honestly if it cannot.

Modes

Three modes, one checkpoint core

  • Resume-onlyCheckpoints and verified restore. No detection.
  • Screen-only nudgesOn-device screen text decides focus. No camera.
  • Full fusionScreen + face cues (face adapter stubbed here), correction memory, verified restore.

All three call the same checkpoint and restore code path.

Install

Extension in three steps

  1. Build the extension: npm run build:extension.
  2. Chrome → chrome://extensions → Developer mode → Load unpacked → extension/dist.
  3. Copy the extension ID into the extension setup dialog here so the page can talk to it.

The web app ↔ extension bridge uses chrome.runtime.sendMessage with externally_connectable, not page injection.
