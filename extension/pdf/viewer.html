PDF route is not in this build

Phases 1–5 were the deadline scope. The bundled PDF.js viewer, page/region checkpoints and text-layer anchor checks were planned for Phase 6 and are deliberately absent rather than half-working.

Web PDFs are listed as unsupported in the README and in the app's supported-content table. The extension still works on normal HTML pages; Google Docs produces a saved-context-only landing because its text layer is not a DOM text layer.

Build plan reference: extension/pdf/README.md in the repository.
